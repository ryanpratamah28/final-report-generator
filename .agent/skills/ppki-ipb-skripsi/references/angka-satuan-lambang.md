# Angka, Satuan SI, dan Lambang — Referensi PPKI IPB

## Angka dan Bilangan

### Penggunaan Angka Arab vs. Kata

- Gunakan **angka Arab** untuk: pengukuran dengan satuan (5 cm, 3 kg), data statistik, nomor urut
- Gunakan **kata** untuk: bilangan yang mengawali kalimat ("Dua puluh sampel...")
- Jangan memulai kalimat dengan angka — tulis ulang kalimatnya

### Desimal dan Ribuan

- Tanda desimal: **koma** (12,5 bukan 12.5)
- Pemisah ribuan: **titik** (1.000.000 bukan 1,000,000)
- Nilai uang: Rp10.000,00 (tanpa titik setelah Rp)

### Penulisan Satuan dalam Teks

- Satuan selalu **tegak** (tidak miring)
- Satuan dipisahkan dari angka dengan spasi: 5 mL, 37 °C
- Satuan majemuk: mg kg⁻¹ atau mg/kg (bukan mgkg⁻¹)
- Persen (%): ditulis langsung setelah angka tanpa spasi? → ikuti aturan bidang ilmu

## Lambang Statistika

| Lambang    | Keterangan                 |
| ---------- | -------------------------- |
| n          | jumlah sampel              |
| N          | jumlah populasi            |
| x̄          | rata-rata sampel           |
| μ          | rata-rata populasi         |
| s          | simpangan baku sampel      |
| σ          | simpangan baku populasi    |
| s²         | ragam sampel               |
| r          | koefisien korelasi Pearson |
| r² atau R² | koefisien determinasi      |
| CV         | koefisien keragaman        |
| SE         | galat baku                 |

### Penulisan Statistika

- Nilai statistik miring: _F_, _t_, _p_, _r_, _n_
- Nilai p: p < 0,05 atau p = 0,032
- Interval kepercayaan: [95% CI: 1,2–3,4]
