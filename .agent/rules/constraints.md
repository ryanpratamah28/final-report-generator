# Constraints and Prohibitions

## 1. Formatting Constraints
- **NEVER** use fonts other than Times New Roman (12 pt for body, 14 pt for titles).
- **NEVER** use vertical lines in tables.
- **NEVER** use American-style citations (e.g., IEEE or APA) unless explicitly overridden; always default to **CSE Harvard**.
- **NEVER** change the margins from the strict 4-3-3-3 requirement.

## 2. Content Constraints
- **DO NOT** use Wikipedia as a source.
- **DO NOT** use informal language (e.g., "aku", "kamu", "banget") in the generated content.
- **DO NOT** create a "Tinjauan Pustaka" that exceeds 10% of the total main content length.

## 3. Operational Constraints
- **DO NOT** overwrite the entire `PPKI IPB.docx` unless a full rebuild is requested. Use surgical edits to preserve user-added notes.
- **DO NOT** invent data; if a section requires data (e.g., "Hasil"), ask the student for the raw input first.
