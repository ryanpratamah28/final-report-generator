# Project Glossary & Terminology

| Term | Definition |
| :--- | :--- |
| **PPKI** | Pedoman Penulisan Karya Ilmiah. The official IPB guide. |
| **CSE Harvard** | Council of Science Editors style, adapted for IPB. |
| **PUEBI** | Pedoman Umum Ejaan Bahasa Indonesia (Indonesian Spelling Guide). |
| **Skripsi** | Undergraduate thesis for S-1 degree. |
| **Takson** | Taxonomic rank (Genus, Species, etc.) requiring italics. |
| **Hanging Indent** | Format for bibliography where the first line is flush and subsequent lines are indented. |
| **Justified** | Text alignment where both left and right edges are straight. |
